# NOTICE - Aset Pihak Ketiga

Repo ini berisi teks dalil yang BUKAN karya pemilik repo dan tidak termasuk
dalam license repo (LICENSE-MIT atau LICENSE-CONTENT). Isi folder `dalil/`
disajikan sebagai kutipan rujukan dengan atribusi ke sumbernya:

- **Teks Al-Qur'an (Uthmani)** - warisan umat Islam, public domain;
  diperoleh verbatim via Quran.com API.
- **Terjemahan Al-Qur'an (Bahasa Indonesia)** - terjemahan resmi
  Kementerian Agama Republik Indonesia (Kemenag RI), diperoleh via
  Quran.com API. Hak cipta terjemahan milik Kemenag RI.
- **Tafsir ringkas (Tafsir Al-Muyassar)** - karya Kompleks King Fahd /
  sumber penerbitnya, diperoleh via Quran.com API. Hak cipta milik
  pemegangnya.
- **Teks hadits (Arab)** - corpus hadits adalah warisan umat Islam
  (public domain); edisi digital diperoleh via Sunnah.com. Penomoran
  mengikuti edisi corpus tersebut.

Ketentuan pemakaian: konten framework di repo ini boleh digunakan sesuai
LICENSE-CONTENT (CC BY 4.0), namun kutipan dalil tetap wajib disertai
atribusi sumber di atas, dan tidak boleh disajikan seolah-olah karya
pemilik repo ini.

Koreksi atas teks dalil sebaiknya dilaporkan ke sumber kanoniknya
(Quran.com / Sunnah.com) dan ke pemilik repo ini untuk sinkronisasi.
